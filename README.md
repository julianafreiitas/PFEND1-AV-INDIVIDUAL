# PFEND1-AV-INDIVIDUAL

## Executar a aplicação

Os dados de treinamentos, funcionários e vencimentos são salvos em `frontend/data/training-data.json`. O arquivo é criado automaticamente no primeiro cadastro e permanece entre reinicializações. A API faz parte do frontend; não é necessário iniciar um servidor backend separado nem configurar banco de dados.

Inicie o frontend:

```powershell
cd frontend
npm run dev
```
